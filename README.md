# tv-logos

A collection of TV channel logos in PNG format, covering Romanian, Moldovan, and international channels, for use with IPTV playlists and media centres such as Kodi, Plex, and Jellyfin.

## ✨ Features

- PNG format logos for over 300 TV channels
- Covers Romanian, Moldovan, and international channels
- GIMP XCF source files included for select logos
- Suitable for IPTV playlists, Kodi, Plex, Jellyfin, and other media centres

## 🚀 Usage

Reference a logo directly using its raw GitHub URL:

```
https://raw.githubusercontent.com/hmlendea/tv-logos/master/logos/CHANNEL_NAME.png
```

For example, to use the `Pro TV` logo:

```
https://raw.githubusercontent.com/hmlendea/tv-logos/master/logos/pro_tv.png
```

Alternatively, clone the repository to use the logos locally:

```bash
git clone https://github.com/hmlendea/tv-logos.git
```

## 🗂️ Project Structure

| Directory  | Purpose                                      |
|------------|----------------------------------------------|
| `logos/`   | PNG logo files for each TV channel           |
| `sources/` | GIMP XCF source files for select logos       |
